# Study MBBS Abroad - Responsive Landing Page

## Project Overview
This project is a **responsive landing page** for "Study MBBS Abroad," designed for University Insights. The page includes key sections such as a **hero banner, country listings, admission process, and a lead generation form**. The page is built using **HTML, Tailwind CSS, and JavaScript** to ensure a fast-loading, SEO-optimized, and mobile-friendly experience.

## Features
- **Hero Section:** Engaging banner with a CTA ("Apply Now for MBBS Abroad").
- **Why Study MBBS Abroad:** Highlights key benefits.
- **Top Countries:** Includes Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, and Egypt.
- **Admission Process & Eligibility:** Step-by-step guidance.
- **Lead Generation Form:** Users can submit their name, email, phone number, and country preference.
- **Form Validation:** Ensures required fields are filled before submission.
- **SEO Optimization:** Fast loading, proper meta tags, and structured content.

## Technologies Used
- **HTML** - Structure of the page
- **Tailwind CSS** - Styling and responsiveness
- **JavaScript** - Form handling and validation

## Installation & Setup
1. **Clone the repository**:
   ```sh
   git clone https://github.com/GouthamGopu/StudyMBBS-Abroad.git
   cd StudyMBBS-Abroad
   ```

2. **Open `index.html` in a browser** to view the page.


## Form Handling & Validation
- The form captures **Full Name, Email, Phone Number, and Country Preference**.
- **JavaScript validation** ensures required fields are filled before submission.
- **Data is stored temporarily** in an object and logged to the console.

## SEO & Performance Optimization
- **Mobile-first design** for responsiveness.
- **Optimized images and lazy loading** for faster page speed.
- **Meta tags and semantic HTML** for better search engine ranking.
